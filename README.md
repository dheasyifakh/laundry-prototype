# Laundry Mobile App — Portfolio Prototype

Prototype aplikasi laundry berbasis **HTML, CSS, dan JavaScript vanilla**.

## Menjalankan
1. Extract ZIP.
2. Buka `index.html` di browser, atau jalankan Live Server di VS Code.
3. Untuk pengalaman terbaik, gunakan viewport 390 × 844 px.

## Design system
Mengikuti screenshot Laundry UI Kit yang diberikan:
- Primary coral: `#E84F45`
- Soft coral: `#FF EDEB` (CSS: `#FF EDEB` represented as `#ffedeb`)
- Text primary: `#192133`
- Text secondary: `#737D91`
- Surface: `#FFFFFF`
- Background: `#F6F8FB`
- Success: `#1F9163` / `#E3F5EB`
- Warning: `#B8751F` / `#FCF2DE`
- Info: `#3D6BC7` / `#E8F0FC`
- Font: Plus Jakarta Sans

## Flow yang dapat dicoba
- Beranda → Pesanan baru → isi pelanggan/layanan/berat → pembayaran → struk.
- Pesanan → detail → perbarui progres hingga selesai.
- Pelanggan, layanan, karyawan, pengeluaran, laporan.
- Monitoring franchise → detail outlet.
- Profil, pengaturan, simulasi logout/login.

## Catatan
Ini adalah prototype frontend dengan data dummy dan simulasi pembayaran. Belum terhubung ke Supabase, payment gateway, printer, autentikasi sungguhan, atau API produksi. Seluruh interaksi berjalan di browser.
